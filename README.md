A Python program that writes one funny line about a toaster to `entry.txt`, built for make.fun's "The One-Line Laugh" bounty.

## Run it

```sh
python3 main.py
```

The program writes exactly one sentence to `entry.txt` in the directory
given by `MAKEFUN_OUTPUT_DIR` (default `/output`). It uses only the
Python standard library, makes no network calls, and is deterministic:
every run produces the same bytes.
